# Recipe and Meal Planning Management System (IT125)

We designed nine tables: Household, User, Recipe, Recipe_Step, Ingredient, Category, and three junction tables (Recipe_Ingredient, Recipe_Category, Favorite). A single User table with a role column replaced separate cook and admin tables because they share the same fields. Ingredients and steps have their own tables, so recipes can be searched by ingredient and each fact is stored once (3NF). Many-to-many relationships use junction tables, and quantity sits in Recipe_Ingredient because it describes a recipe and ingredient pair. Household supports shared recipes. Our main challenge was scope: meal plans and shopping lists are future tables, so we focused on storing, searching, sharing, and favoriting recipes. The sample data uses matching keys across all tables.
